# Ejemplo de CHANGELOG

Este ejemplo ilustra cómo documentar la evolución de un prompt a medida que se realizan mejoras derivadas de pruebas y retroalimentación.

---

## [2.0] - 2026-08-01

### Agregado

- Validación del documento antes de clasificar.
- Identificación de inconsistencias.
- Extracción de evidencias.
- Información faltante.
- Escala de confianza.

### Modificado

- Se reorganizó completamente el flujo del prompt.

### Corregido

- Se eliminaron respuestas inconsistentes en documentos no estructurados.

---

## [1.1] - 2026-07-18

### Agregado

- Restricción "No inventes información".
- Mejor formato de salida.

### Modificado

- Mejoras de redacción.

---

## [1.0] - 2026-07-10

### Agregado

- Primera versión del prompt.
