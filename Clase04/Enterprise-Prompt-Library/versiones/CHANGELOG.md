# CHANGELOG

Todos los cambios importantes realizados en esta Enterprise Prompt Library serán registrados en este documento.

El formato utilizado sigue el principio **Keep a Changelog**, adaptado al versionado de prompts.

# [2.0] - 2026-08-01

## Agregado

- Nueva fase de interpretación del documento.
- Extracción estructurada de evidencias.
- Identificación de información faltante.
- Detección de inconsistencias.
- Escala objetiva para el nivel de confianza.
- Prompt Scorecard.
- Prompt Evaluation Report.
- Prompt Test Suite.

## Modificado

- Reestructuración completa del prompt de clasificación.
- Mejoras en la justificación.
- Mejor organización del formato de salida.

## Corregido

- Eliminadas inferencias no justificadas.
- Corrección de ambigüedades en la clasificación.
