# Prompt Engineering Avanzado

## Clase 2
### Diseño de Prompts para Automatización y Optimización de Procesos

---

## ¿Qué aprenderemos hoy?

En esta sesión avanzaremos desde la creación de prompts individuales hacia el diseño de **prompts reutilizables**, organizados como componentes dentro de una biblioteca empresarial.

A través de ejemplos reales construiremos una **Enterprise Prompt Library**, aplicando principios de reutilización, parametrización y documentación para facilitar la automatización de procesos organizacionales mediante IA generativa.

---

### Idea clave

> **Un buen prompt resuelve una tarea.  
> Una biblioteca de prompts permite escalar esa solución a toda una organización.**
