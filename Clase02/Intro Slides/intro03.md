# Objetivos de Aprendizaje

Al finalizar la sesión el estudiante será capaz de:

✅ Diseñar prompts reutilizables mediante plantillas parametrizadas.

✅ Organizar una biblioteca de prompts siguiendo buenas prácticas de ingeniería de software.

✅ Documentar prompts utilizando una estructura estándar.

✅ Construir un Starter Kit para automatización de procesos con IA generativa.

✅ Comprender la importancia de separar datos, prompts y documentación para facilitar el mantenimiento y la escalabilidad.
