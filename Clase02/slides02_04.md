# ¿Qué es una Enterprise Prompt Library?

Una **Enterprise Prompt Library (EPL)** es una colección organizada de prompts, plantillas y documentación diseñada para facilitar la automatización de procesos mediante IA Generativa.

## Objetivos

- Centralizar el conocimiento.
- Evitar duplicación.
- Favorecer la reutilización.
- Facilitar mantenimiento.
- Permitir colaboración entre equipos.
- Preparar la integración con herramientas de automatización.

## Beneficios

| Biblioteca Personal | Enterprise Prompt Library |
|----------------------|--------------------------|
| Uso individual | Uso organizacional |
| Pocos prompts | Biblioteca estructurada |
| Sin documentación | Documentación completa |
| Difícil mantenimiento | Evolución controlada |

> **Idea clave**

Una EPL es el equivalente a una biblioteca de componentes reutilizables en Ingeniería de Software.

::: notes

### Objetivo docente

Relacionar con librerías de software, APIs y repositorios Git.
